## Overview

Happy Greens is a grocery e-commerce web application built to demonstrate a complete online shopping experience for a small grocery business.

> **Note:** This is an independent project built to showcase full-stack development skills, not a commissioned client project.

## What It Does

- **Product catalog** with categories, search, and filtering
- **Shopping cart** with quantity management and price calculation
- **Checkout flow** with order summary
- **Responsive design** that works on mobile, tablet, and desktop

## How It Was Built

The application was built with **Next.js** and **React** for the frontend, styled with **Tailwind CSS**, and structured to demonstrate modern e-commerce patterns.

Key technical decisions:

- **Server-side rendering** for fast initial page loads and SEO
- **Component-based architecture** for maintainable, reusable code
- **Responsive-first design** ensuring usability across all screen sizes

## What It Demonstrates

This project shows the ability to:

- Design and build a complete web application from scratch
- Handle real-world e-commerce requirements (cart state, product data, checkout logic)
- Write clean, maintainable code following current best practices
- Create a polished user experience with attention to detail
